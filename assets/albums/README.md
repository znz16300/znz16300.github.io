# Альбоми малюнків у кіоску

Альбом — це звичайна **папка з малюнками** + файл **`album.json`** у ній.
Кіоск показує альбом на повноекранній сторінці з жестами (свайп, масштабування, прокрутка).
Для нового пункту меню (плитки) **не потрібно писати код сторінки** — один загальний компонент
`src/pages/Kiosk/AlbumViewer.tsx` і один загальний маршрут `/kiosk/album/:folder` працюють для всіх альбомів.

```
public/assets/albums/
├── README.md                 ← цей файл
└── healthy-food/             ← папка альбому («Здорове харчування»)
    ├── album.json            ← назва + перелік файлів
    ├── 01-principles.jpg
    ├── 02-food-pyramid.jpg
    └── ...
```

## Формат `album.json`

```json
{
  "title": "Здорове харчування",
  "files": [
    "01-principles.jpg",
    "02-food-pyramid.jpg",
    "03-healthy-food-day.jpg"
  ]
}
```

- `title` — назва пункту меню; вона ж виводиться у заголовку сторінки альбому.
- `files` — імена файлів **у тому порядку, у якому вони листатимуться**. Файли лежать у цій самій папці.

## Як додати новий пункт (плитку) з малюнками — 3 кроки

**1. Створіть папку й покладіть у неї малюнки**

```
public/assets/albums/<папка>/
```

`<папка>` — коротка назва латиницею без пробілів, наприклад `fire-safety`, `road-rules`.

**2. Створіть `album.json`**

Вручну (формат вище) або автоматично, однією командою з кореня проєкту:

```bash
node scripts/make-album.mjs fire-safety "Пожежна безпека"
```

Скрипт збере всі малюнки папки (jpg, png, gif, webp, svg, avif) у порядку за іменами й запише `album.json`.
Порядок можна потім змінити вручну в `album.json`.

**3. Додайте плитку в меню**

Відкрийте `src/pages/Kiosk/kiosk_data.tsx`, знайдіть потрібне меню (наприклад `educationConfig` — розділ «Навчання»
або `mainMenuConfig` — головне меню) і додайте один рядок:

```ts
{ label: 'Пожежна безпека', image: '🧯', link: '/kiosk/album/fire-safety', color: 'red' },
```

Де:
- `label` — підпис на плитці (бажано збігається з `title` в `album.json`);
- `image` — емодзі на плитці;
- `link` — завжди `/kiosk/album/` + **ім'я папки**;
- `color` — `blue`, `purple`, `green`, `orange`, `red`, `teal`, `indigo`, `pink`.

Готово — нічого перебудовувати в коді не потрібно, окрім звичайної збірки проєкту (`npm run build`),
якщо кіоск працює зі зібраної версії `dist`. Малюнки та `album.json` підхоплюються при відкритті сторінки.

> Меню показує максимум **12 плиток** (сітка 4×3). Якщо плиток більше, зайві не відображаються.

## Додавання/заміна малюнків в існуючому альбомі

1. Скопіюйте файл у папку альбому.
2. Додайте його ім'я в `files` у `album.json` (або знову запустіть `node scripts/make-album.mjs <папка>` —
   назва збережеться, список файлів оновиться).
3. Щоб прибрати малюнок — видаліть рядок з `album.json` (і, за бажанням, сам файл).

## Поради щодо файлів

- Імена файлів краще писати **латиницею без пробілів** (`01-vitamins.jpg`). Кирилиця і пробіли теж працюватимуть,
  але можуть ламатися при перенесенні між Windows/macOS/сервером.
- Якщо потрібний порядок, починайте імена з номерів: `01-…`, `02-…`, … `10-…`.
- Розмір: для екрана кіоску достатньо 1500–2500 px по довшій стороні. Дуже великі файли (кілька МБ) завантажуються повільно.
- Формати: JPG, PNG, WebP, GIF, SVG.

## Керування в альбомі

| Дія | Жест |
|---|---|
| Наступний / попередній малюнок | свайп вліво / вправо (також стрілки на екрані, ←/→ на клавіатурі) |
| Збільшити / зменшити | розведення / зведення двох пальців (також кнопки «+» «−», колесо миші) |
| Прокрутити збільшений малюнок | потягнути одним пальцем у будь-який бік |
| Перейти до сусіднього малюнка, будучи збільшеним | довести малюнок до краю й потягнути далі |
| Швидко збільшити / повернути масштаб | подвійний дотик |
| Показати панелі | торкнутися екрана (панелі ховаються через 3 с бездіяльності) |

## Якщо щось не працює

| Симптом | Причина |
|---|---|
| «Альбом не знайдено або він порожній» | немає `album.json` у папці, папка названа інакше, ніж у `link`, або `files` порожній / JSON з помилкою (зайва кома, лапки) |
| Плитка є, але порожній екран замість малюнка | ім'я файлу в `files` не збігається з реальним (регістр літер важливий: `.JPG` ≠ `.jpg`) |
| Нова плитка не видна | її більше 12-ї в меню, або не виконано `npm run build` для зібраної версії |
