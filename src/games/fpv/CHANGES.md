# FPV: зміни
- Під час польоту верхня панель сторінки ховається (shared/GameChrome.tsx + GamePage.tsx), поле на весь екран.
- scenery.ts: 5 видів дерев (ялина, сосна, дуб, береза, тополя) і будівлі (будинок, комора, хата, вежа) з колізіями.
- drone.ts: вибір якості дрона (Навчальний / Стандартний / Професійний).
- settings.ts + Slider.tsx: налаштування стіків (localStorage, ключ kiosk-fpv-stick-settings).
- Stick.tsx: нові необов'язкові пропси travel, trail та метод show(); стіки рухаються і від клавіатури.
