# Козацькі двобої (src/games/duel)
Файтинг без крові: 4 бійці (Козак, Відьма, Лісовик, Мавка) + бос Змій Горинич. Режими: проти комп'ютера (3 рівні), турнір (3 суперники + бос, рекорд зберігається), двоє гравців.
Гра реєструється автоматично (index.ts, order 90) — інших файлів міняти не треба.
Клавіші: гравець 1 — A/D, W, S, F, G, H; гравець 2 — ←/→, ↑, ↓, K, L, ;. Пауза — Пробіл/P/Esc. Є екранні кнопки (мультитач).
Файли: engine.ts (логіка + ШІ), fighters.ts (бійці), draw.ts (малювання), DuelGame.tsx (інтерфейс).
