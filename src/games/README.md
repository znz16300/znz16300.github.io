# Ігри кіоску

Усі ігри лежать у `src/games/<id>/`, кожна — у своїй папці. Меню «Ігри» (`/kiosk/games/arcade`) будується
**автоматично** з усіх папок, у яких є `index.ts`. Додавати гру в роутер чи меню вручну **не потрібно**.

```
src/games/
├── types.ts            ← формат опису гри (GameDefinition, defineGame)
├── registry.ts         ← автоматично знаходить src/games/*/index.ts
├── GamePage.tsx        ← спільна оболонка гри: заголовок, «Назад», «Головне меню»
├── GamesMenuPage.tsx   ← підменю «Ігри» (плитки з реєстру)
├── shared/             ← спільні шматки: GameOverlay, HoldButton, GameLayout, useFitBox, useGameLoop, useHighScore
├── pong/               ← Pong (з комп'ютером або двоє гравців)
├── tetris/             ← Тетріс
├── snake/              ← Змійка
├── platformer/         ← «Лисик-стрибун» (платформер; рівні в levels.ts)
├── fpv/                ← FPV-симулятор (levels.ts - рівні складності й траси, sim.ts - фізика, render.ts - 3D)
├── invaders/           ← «Захист галактики» (шутер проти прибульців)
├── kolobok/            ← «Колобок у лабіринті» (maze.ts - карта лабіринту, engine.ts - рух і ШІ звірів)
└── cossack/            ← «Козак у підземеллі» (платформер-пригода; levels.ts - карти рівнів, engine.ts - фізика й бій, draw.ts - графіка)
```

## Як додати нову гру

1. Створіть папку `src/games/<id>/` (id — латиницею, наприклад `memory`).
2. У ній — два файли.

**`index.ts`** (опис гри — плитка в меню):

```ts
import { lazy } from 'react';
import { defineGame } from '../types';

export default defineGame({
  id: 'memory',                 // збігається з назвою папки; потрапляє в URL /kiosk/games/play/memory
  title: 'Пам\'ять',            // підпис на плитці й заголовок сторінки
  icon: '🃏',                   // емодзі на плитці
  color: 'orange',              // blue | purple | green | orange | red | teal | indigo | pink
  order: 40,                    // порядок у меню (менше - раніше)
  component: lazy(() => import('./MemoryGame')),
});
```

**`MemoryGame.tsx`** (сама гра — React-компонент, що займає всю область: `w-full h-full`):

```tsx
import React from 'react';

const MemoryGame: React.FC = () => (
  <div className="w-full h-full flex items-center justify-center text-white text-3xl">Моя гра</div>
);

export default MemoryGame;   // обов'язково default-експорт
```

Готово: плитка з'явиться в «Ігри та тести → Ігри».

## Корисне зі `shared/`

| Що | Для чого |
|---|---|
| `useFitBox(aspect)` | розмір поля із заданими пропорціями, що вписується в доступну область |
| `useGameLoop(cb)` | цикл `requestAnimationFrame`, `cb(dt)` — секунди між кадрами |
| `GameLayout` | розкладка «інфо — поле — кнопки» (на вертикальному екрані — поле зверху) |
| `GameOverlay`, `GameButton`, `GameChip` | екрани старту / паузи / кінця гри |
| `HoldButton` | сенсорна кнопка з повтором при утриманні |
| `Stick` | віртуальний стік пульта (коло, що перетягується; мультитач; може не повертатися по вертикалі - як газ) |
| `PressButton` | кнопка «натиснуто/відпущено» для керування утриманням (мультитач) |
| `useHighScore(id)` | рекорд у `localStorage` браузера кіоску |

Зручно починати з копії папки `snake/` або `pong/`.

## Керування в іграх

| Гра | Дотик | Клавіатура |
|---|---|---|
| Pong | вести пальцем по екрану: у режимі з комп'ютером — будь-де, у режимі двох гравців — кожен по своїй половині | W/S (лівий), ↑/↓ (правий), Пробіл — пауза |
| Тетріс | екранні кнопки ◀ ▶ ▼ ⟳ ⤓ | ← → ↓, ↑ поворот, Пробіл — скинути, P — пауза |
| Змійка | свайп по полю або стрілки на екрані | стрілки / WASD, Пробіл — пауза |
| Лисик-стрибун | кнопки ◀ ▶ та ⤒ (стрибок, можна одночасно; чим довше тримаєте — тим вище) | ← → / A D, Пробіл/↑/W — стрибок, P — пауза |

Новий рівень платформера: допишіть об'єкт у `platformer/levels.ts` (формат описаний у коментарі на початку файлу).
| FPV-симулятор | два віртуальні стіки (Mode 2): лівий — газ/рискання, правий — тангаж/крен. Запуск: лівий стік вниз, потім назад вгору | W/S газ, A/D рискання, стрілки тангаж/крен, P — пауза |

Нова траса або рівень складності FPV: додайте запис у `fpv/levels.ts` (параметри описані в коментарі на початку файлу): режим польоту, розмір воріт, тяга, ліміт часу, координати воріт.
| Захист галактики | кнопки ◀ ▶ 🔥, або вести пальцем по полю (дотик - постріл) | ← → / A D, Пробіл — постріл, P — пауза |
| Козак у підземеллі | ◀ ▼ ▶ ходьба/присісти, ▲ стрибок (у повітрі біля краю - ухопитися, ще раз ▲ - залізти), ⚔ удар, 🛡 захист (утримувати) | ← → ↑ ↓, Z — удар, X — захист, P — пауза |

Новий рівень «Козака»: допишіть карту в `cossack/levels.ts` (текстова карта, умовні знаки описані на початку файлу). Усі рівні мають висоту 12 рядків; поверхи розташовуйте через 3 клітинки по вертикалі — саме на таку висоту герой дістає, ухопившись за край.
| Колобок у лабіринті | свайп по полю або стрілки на екрані | стрілки / WASD, Пробіл — пауза |

Новий лабіринт «Колобка»: змініть `kolobok/maze.ts` (умовні знаки в коментарі; ширина 19, висота 21, ряд тунелю 10, симетрія бажана). Перевірте, що всі проходи зв'язані й немає глухих кутів.
