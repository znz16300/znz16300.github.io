# Нові сторінки /kiosk/games/physics

Додано 12 сторінок за списком «Ідеї сторінок». Раніше вже були: gravity, thunder, mythfact.

| Папка | Сторінка | Що всередині |
|---|---|---|
| `cannon` | Гармата козаків | Кут і сила пострілу, ціль через Дніпро; гра на 10 цілей (мінімум пострілів) |
| `pendulum` | Маятник і час | Довжина/маса/кут, вимірювання періоду; гра «налаштуй період» |
| `waves` | Музика хвиль | Ноти, осцилограф, частота й гучність; гра «вгадай ноту на слух» |
| `laser` | Лазерний лабіринт | Закон відбивання, призма й веселка; 8 рівнів із дзеркалами |
| `circuit` | Електричне коло | Батарея, лампи, вимикач, послідовно/паралельно; гра «знайди перегорілу лампочку» |
| `buoyancy` | Плаває чи тоне? | Предмети й рідини, густина; гра «передбач і перевір» |
| `lever` | Важіль-гойдалка | Моменти сил; гра «врівноваж найменшою кількістю гир» |
| `states` | Три стани речовини | Частинки льоду/води/пари, термометр; гра «закип'ятити вчасно» |
| `magnets` | Магніти й компас | Залізні ошурки, компас; лабіринт для кульки з магнітом |
| `speed` | Швидкість, час, відстань | Перегони машин; гра «хто приїде першим» |
| `ukrainians` | Українські фізики | Галерея (Корольов, Сікорський, Ландау, Дніпрогес, Пулюй, Смакула, Кондратюк, Патон) + міні-тест |
| `chain` | Конструктор ланцюгових реакцій | Власна 2D-фізика: гірки, доміно, м'ячі, дзвоник; 3 рівні + пісочниця |

## Як це підключається

Нічого міняти не треба. `src/physics/registry.ts` сам знаходить усі `src/physics/<id>/index.ts`
(`import.meta.glob`), тож нові картки з'являються на сторінці фізики, а маршрути — автоматично.
`routes.tsx` та існуючі файли не змінювались. Нових npm-залежностей немає.

Єдиний новий спільний файл — `shared/canvasPointer.ts` (перетворення дотику на координати полотна).
Існуючі компоненти `shared/*` не чіпались.
