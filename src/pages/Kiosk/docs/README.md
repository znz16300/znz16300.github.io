# Універсальний інформаційний кіоск

## 📋 Опис

Це універсальний React-компонент для створення інформаційних кіосків з підтримкою:
- ✅ Різних типів контенту (меню, текстовий контент, iframe)
- ✅ Адаптивного дизайну (десктоп і мобільні пристрої)
- ✅ Анімованих переходів між сторінками
- ✅ Динамічного завантаження даних з JSON файлів
- ✅ TypeScript для type-safety

## 🗂️ Структура файлів

```
src/
├── UniversalKiosk.tsx          # Основний компонент кіоску
├── kiosk-types.ts              # TypeScript типи
├── kulikivka-data.json         # Дані про Куликівську громаду
└── App.tsx                     # Приклад використання з роутингом
```

## 🚀 Швидкий старт

### 1. Встановлення залежностей

```bash
npm install react-router-dom
npm install -D @types/react-router-dom
```

### 2. Використання компонента

```tsx
import { UniversalKiosk } from './UniversalKiosk';
import kioskData from './kulikivka-data.json';

function MyPage() {
  return <UniversalKiosk config={kioskData.mainMenu} />;
}
```

## 📊 Типи конфігурацій

### 1. Меню (Menu Config)

Відображає сітку кнопок для навігації:

```json
{
  "type": "menu",
  "title": "Головне меню",
  "subtitle": "Інформаційний кіоск",
  "buttons": [
    {
      "label": "Історія",
      "link": "/history",
      "color": "blue",
      "image": "📜",
      "disabled": false
    }
  ]
}
```

**Доступні кольори:** `blue`, `purple`, `green`, `orange`, `red`, `teal`, `indigo`, `pink`

### 2. Контент (Content Config)

Відображає текстову інформацію, статистику, таблиці:

```json
{
  "type": "content",
  "title": "Історична довідка",
  "sections": [
    {
      "heading": "Заголовок секції",
      "content": "Текстовий контент...",
      "items": ["Пункт 1", "Пункт 2"]
    }
  ],
  "statistics": [
    {
      "label": "Населення",
      "value": "14 116 осіб",
      "date": "станом на 1 січня 2025 р."
    }
  ]
}
```

### 3. Iframe (Iframe Config)

Вбудовує зовнішній веб-сайт:

```json
{
  "type": "iframe",
  "title": "Назва сторінки",
  "url": "https://example.com"
}
```

## 🔧 Додавання нової сторінки

### Крок 1: Додати дані в JSON

Відкрий `kulikivka-data.json` та додай нову секцію:

```json
{
  "myNewPage": {
    "type": "content",
    "title": "Моя нова сторінка",
    "sections": [
      {
        "heading": "Вітаємо",
        "content": "Це нова сторінка!"
      }
    ]
  }
}
```

### Крок 2: Додати роут в App.tsx

```tsx
<Route 
  path="/mynewpage" 
  element={<UniversalKiosk config={data.myNewPage} />} 
/>
```

### Крок 3: Додати кнопку в меню

У головному меню додай нову кнопку:

```json
{
  "label": "Нова сторінка",
  "link": "/mynewpage",
  "color": "green",
  "image": "✨",
  "disabled": false
}
```

## 📱 Адаптивність

Компонент автоматично адаптується до розміру екрану:

- **Десктоп:** Сітка 4×3 для кнопок меню
- **Мобільні:** Сітка 2×6 для кнопок меню
- Автоматичне масштабування шрифтів та відступів
- Оптимізовані кнопки навігації

## 🎯 Навігація

- **Кнопка "Назад"** - повертає на попередню сторінку
- **Кнопка "Головне меню"** - повертає на головну сторінку (з'являється на всіх сторінках крім головної)
- Плавні анімовані переходи між сторінками

## 💡 Поради

1. **Оптимізація JSON:** Групуй схожі дані в одній секції
2. **Кольори кнопок:** Використовуй різні кольори для різних категорій
3. **Емодзі:** Додавай емодзі як іконки для кращої візуалізації
4. **Disabled кнопки:** Позначай сторінки "Скоро" для майбутніх функцій
5. **Довгий контент:** Для великих текстів використовуй прокрутку

## 🔄 Створення нових JSON файлів

Для різних кіосків можна створювати окремі JSON файли:

```tsx
// school-data.json для шкільного кіоску
import schoolData from './school-data.json';

// city-data.json для міського кіоску
import cityData from './city-data.json';
```

## 📝 Приклад повної конфігурації

Дивись `kulikivka-data.json` для повного прикладу з усіма типами контенту.

## 🐛 Troubleshooting

**Проблема:** Сторінка не відображається  
**Рішення:** Перевір, чи додано роут в `App.tsx`

**Проблема:** Кнопка не працює  
**Рішення:** Переконайся, що `link` співпадає з шляхом в роутах

**Проблема:** Анімація не працює  
**Рішення:** Перевір, чи встановлені Tailwind CSS класи
