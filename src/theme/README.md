# Теми оформлення

```
theme/
  theme.config.ts     ← НАЛАШТУВАННЯ (палітра, режим, перемикачі, кіоск)
  palettes/*.css      ← таблиці стилів: кожна палітра — окремий файл
  base.css            ← семантичні кольори shadcn + автоматична темна тема
  ThemeProvider.tsx   ← застосовує тему, зберігає вибір, слідкує за темою ОС
  ThemeToggle.tsx     ← перемикач «світла / темна / як у системі» (+ палітри)
  initScript.ts       ← ставить тему до завантаження React (без білого спалаху)
  ThemePreviewPage.tsx← /theme-preview — усі палітри поруч (лише в dev)
```

## Змінити палітру перед деплоєм

1. `npm run theme:preview` — подивитися всі палітри у світлому й темному режимі.
2. У `theme.config.ts` змінити `palette: 'classic'` на потрібну.
   Або разово: `VITE_THEME_PALETTE=ukraine npm run deploy` (Windows PowerShell:
   `$env:VITE_THEME_PALETTE='ukraine'; npm run deploy`).
3. В основний CSS потрапляє **лише обрана палітра**. Інші збираються окремими
   файлами й вантажаться тільки якщо `allowUserPalette: true` і відвідувач обрав іншу.

## Як це працює

Tailwind-кольори прив'язані до CSS-змінних палітри (`tailwind.config.ts`):

| Клас у коді | Змінна | Що це |
|---|---|---|
| `bg-brand-600`, `text-brand-500/50` | `--brand-*` | основний колір (раніше `blue-*`) |
| `bg-brand2-600` | `--brand2-*` | додатковий (раніше `emerald-*`, шапки сторінок) |
| `gray-*`, `slate-*`, `neutral-*` | `--neutral-*` | сірі: фони, текст, рамки |
| `bg-background`, `text-primary`… | семантичні з `base.css` | shadcn/ui |

Інші кольори (`red`, `green`, `amber`, `purple`…) — стандартні Tailwind, вони не залежать від палітри.
Тому в новому коді для «фірмових» елементів пишіть `brand`/`brand2`, а не `blue`.

## Нова палітра

1. Скопіюйте `palettes/classic.css` у `palettes/<назва>.css`, змініть `data-palette="<назва>"` і значення
   (формат `R G B`, без коми — напр. `37 99 235`). Шкали 50…950 мають іти від світлого до темного.
2. Додайте `<назва>` у `PALETTES` (`theme.config.ts`) та підпис і зразок у `palettes.ts`.

## Темна тема

- Вмикається класом `.dark` на `<html>`; вибір відвідувача — у `localStorage['theme']`.
- Режим `system` стежить за темою ОС наживо.
- `base.css` **автоматично** затемнює елементи, що мають лише світлі класи (`bg-white`, `text-gray-800`,
  `border-gray-200`, кольорові плашки `bg-green-100`…), якщо в них немає власних `dark:`-класів.
  Власні `dark:`-класи завжди мають пріоритет. Щоб блок лишався світлим (напр. друкована форма) —
  клас `keep-light`. Щоб фото не приглушувалось — `no-dim`.
- Кіоск (`/kiosk…`, `/mainmenu`) за замовчуванням завжди світлий — `kioskMode` у конфігу.
