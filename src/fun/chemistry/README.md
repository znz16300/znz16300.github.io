# Хімія навколо нас — /kiosk/games/chemistry

Новий розділ «Ігор та тестів». Плитка «⚗️ Хімія навколо нас» додана в `src/pages/Kiosk/kiosk_data.tsx` (`gamesConfig`, один рядок),
сам розділ підключено в `src/fun/index.ts` (один імпорт + один елемент списку). `routes.tsx` змінювати не треба —
маршрути будуються з `funSections` автоматично. Нових npm-залежностей немає.

| Папка | Додаток | Що всередині |
|---|---|---|
| `periodic` | 🧪 Періодична система | Клікабельна таблиця 118 елементів, фільтр категорій; гра «Вгадай елемент» |
| `ph` | 🥬 Кислоти й луги | Індикатор із капусти, 14 побутових рідин; нейтралізація; гра «кислота чи луг» |
| `molecules` | ⚛️ Збери молекулу | Збирач із атомів (колекція з 11 молекул); гра «збери за назвою» |
| `balance` | ⚖️ Зрівняй рівняння | 12 реакцій, лічильник атомів у реальному часі |
| `lab` | 🔬 Віртуальна лабораторія | Змішування 20 речовин (20 реакцій з анімацією: газ, осад, колір, тепло); гра «що станеться?» |
| `rates` | 💥 Швидкість реакцій | Симуляція зіткнень: температура, концентрація, каталізатор, графік; гра «Швидше!» |
| `mixtures` | 🧲 Розділи суміш | 8 завдань на розділення сумішей (порядок кроків має значення) |
| `home` | 🏠 Хімія вдома | Каталог 20 речовин, гра «яка формула?», мемо |
| `quiz` | 🧠 Хімічний квіз | 10 випадкових питань зі спільного банку (≈ 110 питань) |

Усі сторінки мають вкладки «Чи знаєте ви?» і «Перевір себе» (випадкові питання з банку, кожного разу інші).
Рекорди зберігаються в браузері кіоску (`useBest`).
Додати новий додаток: створіть папку `src/fun/chemistry/<id>/` з `index.ts` (`defineFunPage`) — плитка з'явиться сама.
